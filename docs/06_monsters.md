## 몬스터 추가
1. (새 외형이 필요하면) `tools/gen_assets.py` 의 `MONSTER_SPRITES` 에 그리기 함수 추가 후 실행
2. 관리자 '캐릭터·몬스터' 탭 → 몬스터 → ＋ 새 몬스터 (능력치·행동·전리품)
3. '맵 디자인' 탭의 맵 속성에서 출현 그룹에 추가하거나, 시나리오에서 `> battle id`
4. 이 문서의 표를 갱신
