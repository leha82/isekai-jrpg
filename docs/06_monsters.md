# 06. 몬스터 도감

## 인카운트 규칙 ✅

이동한 타일 기준으로 판정하며 `triggerRandomEncounter(tileType)`에서 처리한다.

| 타일 | 출현 확률(한 걸음당) | 출현 풀 |
|---|---|---|
| 0 초원 | 13% | 초원 슬라임 |
| 1 깊은 숲 | 20% | 숲 고블린, 독 슬라임 (각 50%) |
| 6 북부 설원 | 24% | 마왕군 흑기사 |
| 3 흙길 / 5 마을·성 | 0% | — |

| 마왕군 흑기사 | `knight` | 105 | 18 | 55 | 45 | 북부 설원 | 이세계인을 회수하러 나온 마왕군 정예 |

## 보스

### 고대 관리자 마왕 아르카스 ✅

| 항목 | 값 |
|---|---|
| 스프라이트 | `demonLord` |
| HP | 220 |
| ATK | 24 |
| 보상 | EXP 999, Gold 500 |
| 위치 | 북부 마왕성 (17,1) |
| 조건 | `storyFlag ≥ 2` (가렌 합류) |
| 특징 | 도망 불가. 쓰러뜨리면 엔딩 |

- **정체:** 세계를 지키려던 고대 대마법사. 악의는 없고, 세계를 구하려고 유진을 '쐐기'로 쓰려 했다.
- **확장 💡:** HP 50% 이하에서 2페이즈(전체 공격 "차원 붕괴"), 패배 후에도 아군이 될 여지를 남기는 연출.

## 몬스터 추가 아이디어 💡

| 이름 | 지역 | 콘셉트 |
|---|---|---|
| 설원 늑대 | 북부 설원 | 2회 연속 공격 |
| 드워프 골렘 | 드워프 산맥 | 높은 방어력, 마법에 약함 |
| 흑기사 대장 | 설원 입구 | 중간 보스. 처치하면 설원 인카운트 감소 |

## 몬스터 추가 방법

1. 필요하면 `SPRITES`에 새 도트 추가 (기존 스프라이트를 재사용해도 됨)
2. `triggerRandomEncounter()`에서 해당 타일 `pool`에 `{ name, sprite, hp, maxHp, atk, exp, gold }` 추가
3. 이 문서 표에 기록
