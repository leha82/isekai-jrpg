# 05. 전투 시스템

## 개요 ✅

- **방식:** 사이드뷰 턴제 전투, 1 vs 파티(최대 3인)
- **진입:** 인카운트 타일(초원·숲·설원)로 이동할 때 확률 판정 ([06_monsters.md](06_monsters.md)) 또는 보스 이벤트
- **화면 상태:** `gameState = "BATTLE"`, 전투 BGM 재생

## 라운드 흐름

```
[전투 개시] → 유진 행동 → 리아 행동 → 가렌 행동 → [적 행동] → 다음 라운드
                  └ 적 HP 0 → [승리 정산]         └ 파티 전멸 → [패배 처리]
```

1. 합류했고 살아 있는 아군이 파티 순서(유진 → 리아 → 가렌)대로 **각자 커맨드를 고른다**.
2. 아군이 모두 행동하면 적이 **살아 있는 아군 1명을 무작위로** 공격한다.
3. 행동 중간에 적 HP가 0 이하가 되면 바로 승리한다.

> 원본 기획서에는 "유진이 행동하면 동료가 자동으로 연계 스킬을 쓴다"는 안이 있었지만, 실제 구현은 **멤버별로 직접 커맨드를 고르는 방식**이다. 이 방식이 더 전략적이라 그대로 유지한다.

## 커맨드

### 유진 (6칸)
| 커맨드 | MP | 효과 |
|---|---|---|
| ⚔️ 검격 | 0 | `ATK + rand(0~3)` 피해 |
| 🔥 파이어 | 5 | `MATK + rand(0~6)` 피해 |
| ✨ 힐 | 4 | HP 비율이 가장 낮은 생존 아군 1명 HP `20 + floor(MATK × 0.8)` 회복 |
| 🧪 포션 | — | HP가 가장 낮은 생존 아군 1명 HP +45 (포션 1개 소모) |
| 💧 에테르 | — | MP 비율이 가장 낮은 생존 아군 1명 MP +20 (에테르 1개 소모) |
| 🏃 도망 | — | 70% 확률로 전투 이탈. 보스전에서는 불가 |

### 리아 (4칸)
| 커맨드 | MP | 효과 |
|---|---|---|
| 🏹 정밀사격 | 0 | `ATK + rand(0~5)` 피해 |
| 🌪️ 질풍 | 6 | `MATK + 6` 피해 (편차 없음) |
| 💚 전체치유 | 8 | 생존한 아군 전원 HP +28 |
| 🧪 포션 | — | 유진의 포션과 같음 |

### 가렌 (4칸)
| 커맨드 | MP | 효과 |
|---|---|---|
| 🗡️ 강타 | 0 | `ATK + rand(0~3)` 피해 |
| ⚡ 왕가일섬 | 6 | `floor(ATK × 1.65)` 피해 |
| 🛡️ 철벽수호 | 0 | 이번 라운드에 적이 주는 피해 50% 감소 |
| 🧪 포션 | — | 유진의 포션과 같음 |

MP가 모자라거나 아이템이 없으면 로그에 ❌가 뜨고 턴은 넘어가지 않는다. 다시 고르면 된다.

## 데미지 공식

### 아군 → 적
- 위 표의 공식을 그대로 적용한다. **적에게는 방어력 개념이 없다.**

### 적 → 아군
```
damage = max(2, enemy.atk - floor(target.def × 0.5) + rand(0~3))
if (철벽수호) damage = max(1, floor(damage × 0.5))
```

## 승리 / 패배

| 결과 | 처리 |
|---|---|
| 승리 | EXP·골드 획득 → 레벨업 판정 → 필드로 복귀 → **자동 저장** (보스전이면 엔딩으로 이동) |
| 도망 성공 | 보상 없이 필드로 복귀 |
| 전멸 | 시작 지점 (2,6)으로 이동, 파티 HP/MP 완전 회복, 안내 대화 표시 (골드·경험치 손실 없음) |

## 밸런스 메모

- 권장 레벨: 마왕성 Lv.4 이상 (HUD에 안내).
- 가렌의 철벽수호 + 리아의 전체치유 조합이 보스전의 핵심 방어 수단이다.
- 적이 공격을 1회만 하므로 3인 파티의 공격 횟수 이점이 크다. 난이도를 올리려면 적의 다회 공격이나 전체 공격을 넣는 방법을 검토한다.
