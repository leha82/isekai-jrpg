# 05. 전투 시스템

설정 데이터: `data/battle.json`(공식·확률), `data/skills.json`(스킬), `data/monsters.json`(적) · 편집: 관리자 '전투 설정'·'캐릭터·몬스터' 탭

## 개요 ✅
- **방식:** 사이드뷰 턴제. 적 1~3마리(**오른쪽 위**) vs 파티 최대 4인(**왼쪽 아래**, 적을 바라보는 옆모습). ✅ 2026-11-28
- **화면:** 가로 화면 640×300 캔버스, 세로 모드 480×360 캔버스. 배치는 캔버스 크기의 비율로 계산한다 (`enemySlots`, `allySlot`).
- **진입:** 인카운트 타일을 걸을 때 맵별 확률 판정 ([06_monsters.md](06_monsters.md)), 또는 시나리오의 `> battle 적1,적2 [boss] [win=장면]`.
- **전투 후 안전 걸음:** 전투가 끝나거나 맵에 들어온 뒤 4걸음은 인카운트 없음 (`encounterGraceSteps`).
- **배경음:** 일반 `battle`, 보스 `boss`. 승리 시 팡파르.
- **전투 배경:** 맵의 `battleBg` (meadow·forest·town·mountain·snow·castle·dungeon·throne).

## 라운드 흐름
```
[조우] → 주인공 → 리아 → 가렌 (각자 커맨드 선택·연출) → 적 1 → 적 2 → 적 3 → 다음 라운드
            └ 적 전멸 → [승리: 경험치·골드·전리품·레벨업 → 확인]     └ 파티 전멸 → [패배]
```

## 커맨드
| 커맨드 | 설명 |
|---|---|
| 스킬 (캐릭터별 3개) | MP가 모자라면 비활성. 적 하나 대상 스킬은 적이 둘 이상이면 대상 선택 |
| 아이템 | 포션·고급 포션·에테르 → 대상 아군 선택 |
| 도망 | 70% 성공 (`fleeChance`). 보스전에서는 불가 |

- 커맨드 버튼은 글자만 쓴다 (아이콘 없음, 2026-11-28 4차). 왼쪽 위 작은 숫자는 단축키.
- **방향키로 커맨드를 고르고 Enter/Space 로 결정** ✅ (2026-11-28 4차). 2열 격자라 ←→ 는 한 칸, ↑↓ 는 한 줄씩 움직이고, 쓸 수 없는(비활성) 버튼은 건너뛴다. 고른 버튼은 금색 테두리. 마우스를 올려도 커서가 옮겨 간다.
- 숫자 키 1~9 로 바로 고를 수도 있고, Esc/Backspace 로 뒤로 간다.

## 연출 (`js/systems/battle-view.js`)
| 행동 | 연출 |
|---|---|
| 물리 공격 | 캐릭터가 적의 왼쪽 앞까지 달려가 베기 궤적 → 적이 하얗게 번쩍 → 피해 숫자 → 복귀. 왕가일섬은 금빛 3연 참격 + 화면 번쩍임 |
| 정밀사격 · 새총 | 뒤로 반걸음 물러나 화살(날아가는 방향으로 회전) / 돌멩이 발사 |
| 돌멩이 세례 | 적 전체에 돌멩이가 차례로 날아간다 (전체 물리) |
| 빗나감 | 회피에 성공하면 회색 `MISS` |
| 파이어 | 마법진 → 포물선 화염구 → 폭발 파티클 + 화면 흔들림 |
| 질풍 | 적 전체에 바람 소용돌이 |
| 회복 | 초록 고리 + 반짝임, 초록 숫자 |
| 철벽수호 | 아군마다 푸른 육각 방패 |
| 적 공격 | 적이 대상에게 돌진 → 충격 이펙트 → 붉은 숫자 |
| 적 특수기 | 암흑(보라 섬광)·냉기(얼음 조각)·지진(흔들림+흙먼지) |
| 치명타 | 노란 큰 숫자 + 흔들림 |
| 처치 | 서서히 사라짐 + 효과음 |
연출 속도는 `animationSpeed` 로 조절한다 (1 = 기본).

## 피해 공식 (`data/battle.json`)
공격·마력·방어·치명타율·회피율은 5스탯으로 계산한다 — 캐릭터는 [04_characters.md](04_characters.md#5가지-스탯-), 몬스터는 [06_monsters.md](06_monsters.md).
```
물리  = 대상 회피율로 빗나감(MISS) 판정 → max(minDamage, ⌊공격 × 배율 + rand(0..편차) [× critMultiplier 1.6] − 적 방어⌋)
        치명타 확률 = 캐릭터 치명타율(DEX·AGI) + 스킬 crit 보너스
마법  = max(minDamage, ⌊마력 × 배율 + rand(0..편차) − 적 방어 × 0.5⌋)        (빗나가지 않음)
회복  = 고정량 + ⌊마력 × 배율⌋
적 일반 공격 → 아군: 아군 회피율로 MISS 판정, 적 치명타율로 치명타(× critMultiplier)
          = max(enemyMinDamage, ⌊적 공격 × 행동 배율 − 아군 방어 × defenseFactor(0.5) + rand(0..3)⌋)
적 특수기 → 아군: 회피·치명타 없음. 암흑·냉기(dark·frost) 특수기는 적의 **마력**(INT), 그 밖(지진 등)은 공격으로 계산
철벽수호 시 받는 피해 × guardReduction(0.5)
```

## 적 행동 (`monsters.json` 의 `actions`)
각 행동의 `weight`(비중)에 따라 무작위로 고른다. `type: attack`(무작위 아군 하나), `special`(이름·배율·대상 one/all·이펙트).

## 승리 / 패배
| 결과 | 처리 |
|---|---|
| 승리 | 경험치·골드 합산, 전리품(확률) 획득, 레벨업 판정 → '확인' → 필드 복귀. `win=` 장면이 있으면 실행, 없고 일반 전투면 자동 저장(이 기기) |
| 도망 | 보상 없이 필드 복귀 |
| 전멸 | 하젤 마을(부활 위치)로 이동, 전원 회복, `party_wiped` 장면 (골드·경험치 손실 없음) |
