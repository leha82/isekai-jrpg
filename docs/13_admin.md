# 13. 관리자 모드 (`admin.html`)

게임(`index.html`)과 분리된 별도 페이지다. 게임에서 링크하지 않으며 검색에서 제외된다. ✅ (2026-11-27)

| 항목 | 내용 |
|---|---|
| 주소 | https://leha82.github.io/isekai-jrpg/admin.html · 로컬: VS Code F5 → `localhost:8000/admin.html` |
| 접근 | Google 로그인 → Firestore `admin/github` 읽기로 **서버에서** 권한 확인. 최고 관리자 또는 '관리자 지정'에 있는 계정만 들어갈 수 있다 |
| 파일로 직접 열기 | 동작하지 않음 (Firebase 로그인·모듈 로드 불가) |
| GitHub 토큰 | 저장(커밋)에 필요. 처음 한 번 입력하면 Firestore `admin/github` 에 보관 (관리자만 읽기). 상단 '🔐 토큰'으로 변경 |
| 데이터 출처 | 토큰이 있으면 GitHub 최신본, 없으면 배포 사이트 (읽기 전용) |
| 저장 단위 | 탭마다 저장 버튼. 커밋은 GitHub `main` 에 바로 올라가고 1~2분 뒤 게임에 반영 |

### 캐릭터·몬스터의 "디자인" 범위
- 외형은 생성된 스프라이트 중에서 고른다 (캐릭터 17종, 몬스터 13종).
- 능력치 미리보기는 게임과 같은 `js/core/state.js` 의 `calcMemberStats`·`calcMonsterStats` 로 계산한다 (`admin.html` 이 이 파일을 불러온다).
- 새 외형(머리 모양·색·장비 조합, 새 몬스터 모양)은 `tools/gen_assets.py` 의 목록에 추가하고 다시 생성한다. ([12_assets.md](12_assets.md))

## 권한 구조

| 역할 | 누가 | 할 수 있는 일 |
|---|---|---|
| 최고 관리자 | `js/config.js` 의 `MASTER_EMAIL` = `firestore.rules` 의 `isMaster()` | 모든 편집·저장 + 관리자 지정 |
| 관리자 | Firestore `config/admins.emails` 에 있는 계정 | 모든 편집·저장 (관리자 목록 변경 제외) |
| 그 외 | — | 들어갈 수 없음 |
- 이 권한은 Firestore 보안 규칙이 서버에서 강제한다. 관리자 목록 기능을 쓰려면 최신 `firestore.rules` 를 콘솔에 **게시**해야 한다. ([10_firebase_setup.md](10_firebase_setup.md))
- GitHub 커밋은 저장된 토큰(최고 관리자가 만든 fine-grained PAT)으로 한다. 커밋 작성자는 토큰 주인으로 기록된다.

## 작업 흐름
1. 관리자 페이지에서 편집 → 탭의 저장 버튼 → GitHub 커밋 → 1~2분 뒤 게임 반영
2. Claude 와 로컬에서 작업할 때: `git pull` 로 관리자 커밋을 받고, 시나리오는 '📤 전체 내보내기'로 받은 파일을 `scenario-src/` 에 덮어쓴 뒤 작업 → 시나리오 탭 '📁 폴더 가져오기' → 🔒 저장
