# 03. 스토리

## 줄거리

평범한 직장인(이름은 플레이어가 정한다, 기본 '유진')은 퇴근길 지하철에서 눈을 감았다 뜨자 베일하르트의 바람결 초원에 누워 있다.
슬라임에게 습격당한 순간, 몰래 초원에 놀러 나와 있던 하젤 마을의 장난꾸러기 소년 **토비**가 새총으로 그를 구한다. 토비는 주인공을 마을까지 데려다주고, 마을 어귀에서 엄마에게 붙잡혀 집으로 돌아간다.
세계수의 숲에서 만난 엘프 정찰병 **리아**는 그가 이 세계 마력을 전혀 띠지 않은 '쐐기의 이방인'임을 알아보고 왕도까지 동행한다.
루센 국왕은 기사단장 **가렌**을 붙여 주고, 세 사람은 그롬 산길과 서리 평원을 지나 녹턴 요새로 향한다.
문을 지키던 흑기사 대장 **바르구스**를 쓰러뜨리고 옥좌에 이른 일행에게, 세계 관리자 **오르벨**은 균열을 막으려면 이방인의 영혼을 쐐기로 박아야 한다고 말한다.
주인공은 한 사람의 희생 대신 대륙 전체의 마력이 서로를 받치는 **분산 순환**을 그려 균열을 닫고, 동료들과 이 세계에 남는다.

## 스토리 확장 아이디어 💡
- 그롬 드워프 마을과 장비 강화 상한 해제
- 오르벨 2페이즈 (HP 50% 이하에서 패턴 변경)
- 멀티 엔딩: 원래 세계로 돌아가기 / 남기를 선택

## 대사 작성 규칙
- 시나리오 스크립트에 `화자: 대사` 로 쓴다. 주인공은 `{hero}` (입력한 이름으로 바뀜).
- 줄바꿈은 다음 줄을 들여쓰거나 `\n` 을 쓴다.
- 화자 이름에 `리아`·`가렌`·`오르벨`·`국왕`·`촌장`·`토비`·`{hero}` 가 들어가면 대화창에 초상화가 나온다. (`data/characters.json` 의 `speakerPortraits`) — 다른 인물 이름에 이 낱말이 들어가지 않게 한다 (예: 토비의 엄마는 `마르타`).
- 화자 이름을 `?` 로 시작하지 않는다 (`? 조건 -> 장면` 분기 문법과 겹친다).
