# Game Design & Technical Specification: 아르카디아 연대기 (Chronicles of Arcadia)

> **문서 목적:** 본 문서는 AI 코딩 에이전트(Claude Code, Cursor, GitHub Copilot 등)가 게임의 컨셉, 세계관, 스토리, 시스템 아키텍처, 기술 스택, 그리고 현재까지 구현된 기능과 미구현 요구사항(세이브/불러오기 등)을 즉시 이해하고 이어서 개발할 수 있도록 작성된 프로젝트 컨텍스트 명세서입니다.

---

## 1. 프로젝트 개요 (Project Overview)
* **게임 타이틀:** 아르카디아 연대기 (Chronicles of Arcadia)
* **장르:** 2D 도트 그래픽 턴제 JRPG (이세계 전생 판타지)
* **타겟 플랫폼:** 웹 브라우저 (PC 키보드 및 모바일 가상 D-Pad/버튼 겸용)
* **배포 목표:** 단일 파일(`index.html`) 기반 정적 웹 호스팅 (GitHub Pages 배포용)
* **핵심 기술 스택:**
  * HTML5 / CSS3 / Vanilla JavaScript (ES6+)
  * **외부 에셋 의존성 Zero:** 모든 16x16 픽셀 아트는 JS 배열 및 HTML5 `<canvas>`로 런타임 렌더링하며, BGM 및 효과음 역시 Web Audio API(8비트 신디사이저)로 실시간 생성함.

## 2. 세계관 및 스토리 기획 (Lore & Narrative)

### 2.1 세계관 설정: 아르카디아 대륙
* **구성:** 마법을 다루는 **인간 왕국**, 세계수를 수호하는 **엘프 숲**, **드워프 산맥**, 그리고 북동쪽 설원 너머의 **마왕성**이 공존하는 판타지 대륙.
* **핵심 비밀 (논리적 소환 이유):**
  * 아르카디아 세계는 과도한 마법 사용으로 차원의 틈이 벌어져 멸망 직전에 처해 있음.
  * 최종 보스인 **마왕 아르카스**는 단순한 악의 화신이 아니라, 세계의 붕괴를 막으려던 **'고대 대마법사(세계 관리자)'**임.
  * 차원의 균열을 봉인하려면 **'이 세계의 마력에 오염되지 않은 순수한 외부 차원의 영혼(쐐기)'**이 필요했기에 마왕이 차원 소환 술식을 발동했으나, 술식의 오차로 주인공의 영혼이 마왕성이 아닌 **남서쪽 시작의 초원**으로 튕겨 나감.
  * 마왕군이 대륙을 침공하며 이세계인을 추격한 이유는 학살이 아니라 세계를 구할 '열쇠'로 회수하기 위함이었음.

### 2.2 주요 등장인물 (Characters & Party)
1. **유진 (주인공 / 이세계 전생자):**
   * 현대의 평범한 직장인 출신. 영문도 모른 채 초원 한가운데에 떨어짐.
   * 특수 설정: 이세계 마력 회로가 백지상태라 모든 속성 마법과 경험치를 압도적으로 빠르게 흡수함.
   * 전투 역할: 밸런스형 마검사 (물리 공격, 화염 마법 `파이어`, 회복 마법 `힐`).
2. **리아 (엘프 정찰병 / 동료 1):**
   * 동남쪽 '엘프의 숲 성소'에서 조우하는 안내자. 주인공의 순수한 영혼 파장을 가장 먼저 알아봄.
   * 전투 역할: 원거리 딜러 및 광역 서포터 (치명타 사격, 바람 마법, 파티 전체 치유).
3. **가렌 (아르카디아 왕국 기사단장 / 동료 2):**
   * 중앙 북쪽 '아르카디아 왕국'에서 합류하는 역전의 전사.
   * 전투 역할: 탱커 및 고화력 물리 딜러 (강타, 왕가의 일섬, 철벽 방어).
4. **마왕 아르카스 (최종 보스):**
   * 북동쪽 설원 너머 마왕성의 주인. 세계를 지키기 위해 주인공을 제물로 바치려 하나, 최종 결전 후 주인공의 현대적·논리적 발상(개인의 영혼 소모 대신 대륙 전체의 마력 순환 회로를 재설계하는 방식)에 의해 차원이 안정화됨.

### 2.3 스토리 진행 플로우 (Chapter & Quest Flags)
* **`storyFlag = 0` (초반):** 시작의 초원에서 눈을 뜸 → 동남쪽 **엘프의 숲 성소**로 이동해 리아와 조우 (`storyFlag = 1` 전환, 리아 파티 합류).
* **`storyFlag = 1` (중반):** 중앙 북쪽 **아르카디아 왕국** 방문 → 기사단장 가렌과 대화 및 왕가의 명검 획득 (`storyFlag = 2` 전환, 가렌 파티 합류, 마왕성 결계 해제).
* **`storyFlag = 2` (후반):** 북동쪽 설원을 돌파해 **마왕성** 진입 → 마왕 아르카스와의 대화(소환의 진실 공개) 후 최종 보스전 진행.
* **`storyFlag = 3` (엔딩):** 마왕 격파 후 대륙 마력 순환 술식 재설계 → 엔딩 크레딧 및 재시작.

## 3. 핵심 게임 시스템 명세 (Game Mechanics)

### 3.1 월드맵 및 이동 시스템
* **맵 규격:** `20 x 15` 타일 그리드 (타일당 `32x32px`, 기본 캔버스 `640x480px`).
* **타일 타입 정의:**
  * `0`: 초원 (이동 가능, 낮은 확률 인카운트)
  * `1`: 깊은 숲 (이동 가능, 중간 확률 인카운트 - 고블린/독 슬라임)
  * `2`: 물/강 (이동 불가)
  * `3`: 흙길 (이동 가능, 인카운트 없음)
  * `4`: 바위산 (이동 불가)
  * `5`: 마을/성 (이동 가능, 인카운트 없음, 이벤트/회복/상점 트리거)
  * `6`: 북부 설원 (이동 가능, 높은 확률 인카운트 - 마왕군 흑기사)
* **조작 방식:**
  * **PC:** 방향키 (`↑↓←→`) 또는 `WASD` 이동, `Space`/`Enter` 상호작용, `I` 인벤토리/상점 열기.
  * **모바일:** 화면 하단 가상 D-Pad(상하좌우) 및 액션 버튼(확인, 가방/상점).

### 3.2 턴제 전투 시스템 (Turn-Based Combat)
* **전투 트리거:** 인카운트 가능 타일(`0, 1, 6`) 이동 시 난수 판정으로 전투 씬 전환 (`gameState = "BATTLE"`).
* **전투 구조:** `[전투 개시] → [플레이어/파티 행동 선택] → [적 턴 반격] → [승패 및 경험치/골드 정산]`.
* **커맨드 및 파티 연동:**
  * 주인공 유진의 행동(공격, 파이어, 힐, 도망, 아이템 사용) 선택 시 합류한 동료(리아, 가렌)가 자동으로 연계 스킬을 발동.
  * 보스전(`isBossBattle = true`)에서는 도망 불가.

### 3.3 성장, 경제, 상점 및 인벤토리
* **성장:** 전투 승리 시 `EXP`와 `Gold` 획득. `EXP >= nextExp` 도달 시 레벨 업(최대 HP/MP, 공격력, 마법력 상승 및 HP/MP 완전 회복).
* **인벤토리 (`I` 키):**
  * **체력 포션:** HP 회복.
  * **마력 에테르:** MP 회복.
* **상점 시스템 (마을/왕국 방문 시 이용 가능):**
  * 골드를 소모해 포션/에테르 구매 및 **파티 전체 무기 연마(공격력 증가)**, **방어구 강화(최대 HP/방어력 증가)** 영구 업그레이드 가능.

### 3.4 오디오 및 그래픽 엔진 (Zero-Dependency)
* **그래픽:** `PALETTE` 객체와 16x16 문자 배열(`SPRITES`)을 순회하며 `ctx.fillRect`로 픽셀 단위로 렌더링 (`image-rendering: pixelated`).
* **사운드:** Web Audio API(`AudioContext`)를 이용해 Oscillator(사각파/삼각파) 기반 필드 BGM, 전투 BGM, 타격/마법/회복/레벨업 효과음 출력. (사용자 첫 클릭/터치 시 `AudioContext.resume()` 필수 처리).

## 4. 코드 아키텍처 가이드 (Agent Implementation Blueprint)

에이전트가 단일 `index.html` 파일을 작성하거나 리팩토링할 때 아래 상태 머신과 데이터 구조를 유지해야 합니다.

```javascript
// 전역 게임 상태 (State Machine)
// "TITLE" | "WORLD" | "DIALOG" | "BATTLE" | "SHOP_INV" | "ENDING"
let gameState = "TITLE";

// 핵심 세이브 대상 데이터 구조 (JSON 직렬화 가능 형태 유지)
let saveData = {
  player: {
    x: 2, y: 6,
    lv: 1, hp: 60, maxHp: 60, mp: 25, maxMp: 25,
    atk: 14, matk: 20, def: 4,
    exp: 0, nextExp: 20, gold: 50,
    storyFlag: 0, // 0:시작, 1:엘프합류, 2:왕국합류, 3:클리어
    weaponLv: 1, armorLv: 1
  },
  party: {
    ria: false,   // 엘프 궁수 합류 여부
    garen: false  // 왕국 기사 합류 여부
  },
  inventory: {
    potion: 2,
    ether: 1
  }
};
```

## 5. 다음 단계 개발 요구사항 (Next Milestones for Agent)

현재 프로젝트에서 **최우선으로 구현 및 검증해야 할 기능**은 다음과 같습니다.

1. **로컬 스토리지 기반 세이브 / 불러오기 기능 (`localStorage`)**
   * **저장 키:** `'arcadia_isekai_jrpg_save_v1'`
   * **수동 저장 및 불러오기:** 상단 HUD 또는 메뉴 버튼에 `[💾 저장]` 및 `[📂 불러오기]` 버튼을 배치하여 `WORLD` 상태에서 언제든 진행 상황을 저장하고 불러올 수 있도록 구현.
   * **타이틀 화면 연동:** `TITLE` 오버레이 화면에서 기존 세이브 데이터가 존재할 경우 **`[이어하기 (Lv.X)]`** 버튼을 활성화하여 즉시 저장된 위치와 스탯으로 복귀 가능하게 처리.
   * **자동 저장 (Auto-Save):** 주요 스토리 이벤트 완료(`storyFlag` 변경 시) 및 전투 승리 직후 백그라운드 자동 저장 지원 및 화면 우측 상단 토스트 알림(`"저장 완료!"`) 표시.
2. **예외 처리 및 안정성 점검**
   * 브라우저 `AudioContext` 정책으로 인해 첫 사용자 인터랙션 이전에 오디오 호출 시 에러가 발생하지 않도록 `try-catch` 및 상태 체크 적용.
   * 모바일 뷰포트(`max-width: 640px`)에서 화면이 잘리지 않도록 반응형 CSS 스케일링 적용.
