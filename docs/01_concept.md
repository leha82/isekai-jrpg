# 01. 게임 컨셉

## 개요

| 항목 | 내용 |
|---|---|
| 타이틀 | 아르카디아 연대기 (Chronicles of Arcadia) |
| 장르 | 2D 도트 그래픽 턴제 JRPG (이세계 전생 판타지) |
| 플랫폼 | 웹 브라우저 (PC 키보드 + 모바일 가상 패드 겸용) |
| 배포 | 단일 `index.html` 정적 호스팅 (GitHub Pages 목표) |
| 플레이 타임 | 약 20~30분 (현재 버전 기준) |

## 한 줄 컨셉

> 퇴근길 지하철에서 이세계로 떨어진 평범한 직장인이, 동료 둘과 함께 "누군가를 희생시켜야 유지되는 세계"에 다른 해답을 내놓는 이야기.

## 핵심 재미 (Core Pillars)

1. **짧고 완결된 모험** — 한 번 앉은 자리에서 오프닝부터 엔딩까지 볼 수 있는 분량.
2. **동료가 늘어나는 성장감** — 1인 → 2인 → 3인 파티로 전투 선택지가 눈에 띄게 넓어진다.
3. **반전 있는 스토리** — 마왕은 악당이 아니라 세계를 지키려던 관리자. 주인공의 '현대인다운 발상'이 해법이 된다.
4. **어디서나 바로 실행** — 설치·다운로드 없이 브라우저에서 즉시 플레이.

## 디자인 원칙

- **외부 에셋 0개:** 그래픽은 JS 문자열 배열로 그린 16x16 도트, 사운드는 Web Audio 신디사이저로 실시간 생성한다.
- **단일 파일:** 빌드 도구 없이 `index.html` 하나로 동작한다. (분리 리팩터링은 [09_roadmap.md](09_roadmap.md)에서 논의)
- **한국어 우선:** UI, 대사, 주석은 한국어로 작성한다.
- **입력 이중화:** 모든 기능은 키보드와 마우스/터치 버튼 양쪽으로 조작할 수 있어야 한다.

## 톤 & 아트 방향

- 8비트 시절 JRPG의 단순한 색면과 도트. 팔레트는 [08_tech.md](08_tech.md)의 `PALETTE` 참고.
- UI는 짙은 남색 반투명 박스 + 흰 테두리 (고전 RPG 창 스타일).
- 대사는 무겁지 않게, 마왕 관련 장면만 진지한 톤.

## 조작

| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Space / Enter | 조사, 대화 넘기기 |
| I | 가방(인벤토리) |
| Esc | 상점·가방 닫기 |
| 화면 버튼 | 💾 저장, 📂 불러오기, 🔊 소리 ON/OFF |
| 하단 가상 패드 | D-Pad 이동, OK, 가방, 조사/확인 |
