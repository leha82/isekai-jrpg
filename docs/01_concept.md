# 01. 게임 컨셉

## 개요

| 항목 | 내용 |
|---|---|
| 타이틀 | **쐐기의 이방인** — 베일하르트의 균열 |
| 장르 | 2D 도트 그래픽 턴제 JRPG (이세계 전생 판타지) |
| 플랫폼 | 웹 브라우저 (PC 키보드 + 모바일 가상 패드 겸용) |
| 배포 | 정적 호스팅 (GitHub Pages) — 빌드 없이 `index.html` + `js/` + `css/` + `assets/` + `data/` + 암호화 `scenario/` |
| 플레이 타임 | 약 1~1.5시간 (메인 4장 + 서브 퀘스트 2개) |

### 이름을 바꾼 이유 (2026-11-27)
'아르카디아'는 흔한 이름이라, 이야기의 핵심 설정인 **"이 세계의 마력에 물들지 않은 외부 영혼 = 균열을 막는 쐐기"**에서 제목을 따왔다.
대륙은 '장막(veil)'이 갈라지는 땅이라는 뜻의 **베일하르트**다. 지명과 인물 이름도 모두 새로 정했다. ([02_world.md](02_world.md))

## 한 줄 컨셉

> 퇴근길 지하철에서 이세계로 떨어진 평범한 직장인이, '쐐기'로 바쳐질 운명 대신 대륙 전체가 서로를 받치는 새 해답을 찾아내는 이야기.

## 핵심 재미 (Core Pillars)

1. **짧고 완결된 모험** — 12개 맵, 4장 구성으로 한 번에 끝까지 즐길 수 있는 분량.
2. **동료가 늘어나는 성장감** — 1인 → 2인 → 3인 파티로 전투 선택지가 넓어진다.
3. **반전 있는 스토리** — 마왕으로 불리던 '세계 관리자'는 세계를 지키려던 존재였다.
4. **눈과 귀가 즐거운 레트로** — 도트 맵을 걸어 다니는 애니메이션, 캐릭터가 달려 나가 싸우는 전투 연출, 직접 작곡한 배경음.

## 디자인 원칙

- **외부 에셋 0개:** 도트 그래픽·초상화·아이콘·음원을 모두 저장소 안의 생성기(`tools/`)로 만든다. 출처와 라이선스 걱정이 없다. ([12_assets.md](12_assets.md))
  - 예외: 로그인·클라우드 세이브·시나리오 키에 쓰는 Firebase SDK (CDN).
- **빌드 없는 다중 파일:** 코드는 `js/` 아래 역할별 파일로, 게임 데이터는 `data/*.json` 으로, 대화·이벤트·스토리는 암호화된 시나리오 스크립트로 나눈다.
- **데이터와 코드 분리:** 맵·캐릭터·몬스터·스킬·아이템·전투 수치·대사를 바꿀 때 코드를 고치지 않는다. 관리자 페이지에서 편집할 수 있다. ([13_admin.md](13_admin.md))
- **한국어 우선:** UI, 대사, 주석은 한국어로 작성한다.
- **입력 이중화:** 모든 기능은 키보드와 마우스/터치로 조작할 수 있어야 한다.

## 톤 & 아트 방향

- 16x16 도트 타일·캐릭터, 외곽선과 명암이 들어간 8~16비트풍. 맵은 화면을 따라 스크롤된다.
- 초상화는 도트가 아닌 **벡터 일러스트(SVG)** 로, 대화창·HUD·파티 메뉴에 쓴다.
- UI는 짙은 남색 반투명 패널 + 크림색 테두리.
- **브라우저 기본 창(alert·confirm·prompt)은 쓰지 않는다.** 알림·확인은 게임 안의 시스템 창(`uiAlert`/`uiConfirm`)으로 띄운다.

## 조작

| 입력 | 동작 |
|---|---|
| 방향키 / WASD (누르고 있기) | 이동 |
| Space / Enter | 바라보는 상대에게 말 걸기·조사 / 대화 넘기기 |
| P (또는 M) | 파티 |
| I / K / Q | 가방 / 스킬 / 퀘스트 |
| F | 저장·불러오기 창 |
| N | 소리 켜기/끄기 |
| O 또는 Esc | 설정 (창이 열려 있으면 Esc = 닫기) |
| 메뉴가 열린 상태에서 같은 단축키 | 창 닫기 (다른 메뉴 키면 그 탭으로 전환) |
| 알림·확인 창 | ←→ 선택, Enter/Space 결정, Esc 취소 |
| 전투 중 숫자 1~9 | 커맨드 선택 (Esc = 뒤로) |
| 우측 상단 아이콘 | 파티(P) · 가방(I) · 스킬(K) · 퀘스트(Q) · 저장(F) · 소리(N) · 설정(O, 톱니바퀴) — 아이콘 오른쪽 아래에 단축키 표시 |
| 하단 가상 패드 | 누르고 있으면 이동, OK = 조사, 메뉴. 설정에서 보이기/숨기기 |
