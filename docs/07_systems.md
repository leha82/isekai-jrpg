# 07. 게임 시스템 (UI · 퀘스트 · 성장 · 경제 · 세이브)

## 타이틀 화면 ✅
| 버튼 | 동작 |
|---|---|
| ⚔️ 새 게임 | 자동 저장이 있으면 **"새 게임을 시작하면 자동 저장 데이터가 사라집니다"** 확인 창(확인/취소). 확인하면 자동 저장 슬롯(이 기기·클라우드)을 지우고 시작, 수동 슬롯 1~5 는 남는다. 인트로가 끝난 첫 화면에서 새로 자동 저장된다. |
| ▶ 이어하기 | 6개 슬롯 중 가장 최근에 저장된 것으로 시작 (`이름 · Lv · 슬롯` 표시). 저장이 없으면 숨김 |
| 📂 불러오기 | 자동 저장 1 + 수동 5 슬롯 중 골라서 시작 |
| ⚙️ 설정 · 🤖 AI 연결 · 🔑 Google 로그인 | 설정 창(사운드·화면·계정), AI 연결 창([14_ai.md](14_ai.md)), 로그인. 로그인하면 아래에 **플레이어 ID** 와 📋 복사 버튼 |

## 새 게임 ✅
타이틀 → **새 게임** → 주인공 이름 입력(최대 8자, 기본 '유진') → 바람결 초원에서 인트로(토비가 구해 주고 첫 전투 — 튜토리얼 겸 테스트용 동료). 이름은 대사의 `{hero}` 와 HUD·메뉴에 쓰인다.

| 퀘스트 한 줄 (배경 없음) | `[메인/서브] 추적 중인 퀘스트 제목 ▼`. 누르면 드롭다운: 추적 중인 퀘스트의 내용 + 다른 진행 중 퀘스트 제목 목록. 목록을 누르면 그 퀘스트를 추적한다 (`player.focusQuest`, 세이브됨). 고르지 않았으면 메인 퀘스트 |

## 알림·확인 창 ✅
- 브라우저 `alert`/`confirm` 대신 게임 안의 시스템 창(`js/core/ui.js` 의 `uiAlert`, `uiConfirm`, `uiDialog`)을 쓴다.
- 쓰는 곳: 새 게임(자동 저장 삭제), 불러오기, 슬롯 덮어쓰기, 로그아웃, 타이틀로, 로그인 실패, AI 키 지우기, 화면 크기가 창보다 클 때.
- 열려 있는 동안 `gameState = "SYSTEM"` 으로 이동·메뉴 입력을 막고, 닫히면 이전 상태로 돌아간다. 키보드 ←→/Enter/Esc.

## 메뉴 (P·I·E·K·Q·M·O / 아이콘) ✅ (2026-11-28 개편)
| 탭 | 내용 |
|---|---|
| 파티 | 초상화, 이름·역할·Lv, HP·MP·**EXP(숫자+게이지)**, **5스탯(STR·DEX·AGI·CON·INT)** — 공격력·방어력 등 계산값은 보여 주지 않는다. 아래에 스탯별 영향 설명(작게). 캐릭터마다 **✨ 스킬 · 🛡 장비** 버튼 → 그 캐릭터가 선택된 스킬/장비 탭으로. **순서 바꾸기** ▲ ▼ 👑(리더로). 맨 위 = 리더 (맵을 걷는 캐릭터·HUD 주 캐릭터), 전투 행동 순서도 이 순서. 순서는 세이브됨 |
| 가방 | 아이템 아이콘·이름·개수·설명. 회복 아이템은 대상 동료를 골라 사용, 장비는 종류·보너스와 `장비 메뉴` 버튼, 중요 아이템 표시 |
| 장비 | 캐릭터 고르기(초상화 버튼) → 5스탯 → 무기·방어구·장신구 칸마다 지금 장비(해제)와 가방에서 끼울 수 있는 장비 목록(`장착`, 바꾸면 달라지는 스탯 미리보기) |
| 스킬 | 캐릭터 고르기 → 그 캐릭터의 스킬 아이콘·이름·MP·종류·대상·설명. 필드에서 쓸 수 있는 스킬(회복)은 `사용`(대상) 버튼 |
| 퀘스트 | 진행 중 / 완료 (메인·서브 태그, 설명). `🎯 추적하기` / `🎯 추적 중` = HUD 에 한 줄로 보여 줄 퀘스트 |
| 지도 | 월드 지도 + 현재 지역 미니맵 ([02_world.md](02_world.md#지도-메뉴-지도-탭--단축키-m-)) |
| 설정 | 아래 표 |

## 설정 ✅ (2026-11-28 개편)
게임 중에는 메뉴의 설정 탭, 타이틀에서는 ⚙️ 설정 창. 값은 이 브라우저(localStorage)에 저장된다. **순서대로** 표시한다.

| 항목 | 선택지 | 저장 키 |
|---|---|---|
| 저장 / 로드 · 타이틀로 (맨 위, 게임 중만) | `💾 저장` `📂 로드` 창 · `🏠 타이틀로` (확인 창, 모아 둔 자동 저장을 클라우드에 보낸 뒤 이동) | — |
| 사운드 | 전체 · 배경음 · 효과음 볼륨 슬라이더 (0~100), **각 게이지 오른쪽에 켜기/끄기 버튼** (`🔊 켜짐`/`🔇 꺼짐`). 전체 켜고 끄기는 HUD 🔊 아이콘(N)과 같다 | `audio_settings` (`muted`·`bgmMuted`·`sfxMuted`) |
| 화면 모드 | **PC (전체화면)** · **PC (창 모드)** · **모바일 (세로 모드)** · **모바일 (가로 모드)**. 처음 실행하면 기기에 맞춰 고른다 (터치 기기: 화면 방향에 따라 모바일 세로/가로, 그 밖: PC 창 모드). 전체화면은 Esc 로 나가면 창 모드로 바뀌고, 새로 열면 창 모드로 시작한다 | `display_settings.mode` |
| 화면 크기 | 창에 맞춤 · 480×360 · 640×480 · 800×600 · 960×720 · 1280×960 (세로 모드는 가로·세로가 바뀐 360×480 … 960×1280). **지금 창보다 큰 크기를 고르면 알림 후 '창에 맞춤'으로 바꾼다.** 전체화면에서도 고를 수 있다 | `display_settings.size` |
| 가상 패드 | 보이기 · 숨기기. PC: 게임 화면 아래 / 모바일: 필드 위에 겹쳐 표시(전투·대화·메뉴 중 자동 숨김) | `display_settings.pad` |
| 화면에 보이는 맵 크기 | 10 · 13 · 16 · 20 · 26칸 (세로 모드는 긴 변 기준) | `view_cols` |
| 계정 · AI | Google 로그인/로그아웃, **플레이어 ID + 📋 복사**, 🤖 AI 연결 | — |

- 게임 내부 해상도는 가로 화면 640×480, **세로 모드 480×640** (캔버스 크기가 바뀐다). 바깥 크기는 CSS 배율로만 바꾼다 (`js/core/display.js`).
- 창에 맞춤 배율 상한: PC 창 모드 2배, 전체화면 4배.

## 퀘스트 ✅
- 정의: 시나리오의 `@quest id main|side 제목` (+설명). 상태: 없음 → 진행 중(`> quest start`) → 완료(`> quest done`).
- 조건식에서 `quest id active|done|none` 으로 분기한다. 시작·완료 시 알림이 뜬다.
- 메인 4개, 서브 2개 ([03_story.md](03_story.md)).

## 성장 ✅
- 경험치·레벨은 파티 공용. 시작 Lv.1, 다음 레벨까지 20. 파티 메뉴에 캐릭터마다 EXP 숫자와 게이지가 나온다.
- 능력치는 5스탯 + 장비 + 대장간 강화로 계산한다 ([04_characters.md](04_characters.md#5가지-스탯-)).
- 필요 경험치: `nextExp = ⌊nextExp × 1.45⌋` (`data/battle.json` 의 `levelCurve`)

| Lv | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|---|---|
| 필요 EXP | 20 | 29 | 42 | 60 | 87 | 126 | 182 | 263 | 381 |

- 레벨업 성장치(스탯·기본 HP/MP/방어)는 캐릭터마다 다르다 ([04_characters.md](04_characters.md)).

## 세이브 / 불러오기 ✅
| 항목 | 내용 |
|---|---|
| 슬롯 | **자동 저장 1개**(`auto`) + **수동 저장 5개**(`1`~`5`) |
| 이 기기 | `localStorage` 키 `wedge_save_auto`, `wedge_save_1` ~ `wedge_save_5`. 슬롯 도입 전 키 `arcadia_isekai_jrpg_save_v1` 은 처음 실행 때 자동 저장 슬롯으로 옮기고 지운다 |
| 클라우드 | Google 로그인 시 **모든 저장**(자동 포함)을 Firestore `saves/{uid}/slots/{auto|1..5}` 에도 기록. 다른 기기에서도 같은 슬롯을 불러온다 |
| 형식 | **version 3** — 이름·맵·좌표·방향·레벨·골드·대장간 강화·플래그·퀘스트·변수·추적 퀘스트·**가 본 맵**·인벤토리·파티(HP·MP·합류·**장비**, **배열 순서 = 파티 순서**). 최대 HP·공격 등은 저장하지 않고 불러올 때 다시 계산 |
| 구버전 | version 1(아르카디아 시절)은 변환, version 2 는 그대로 읽고 장비는 캐릭터 기본 장비로, HP/MP 는 새 최대치 안으로 맞춘다 |
| 자동 저장 시점 | ① 전투에서 벗어날 때(승리·도망·전멸 후 부활 — 승리 장면이 이어지면 그 대화가 끝날 때) ② 다른 맵으로 이동했을 때 ③ NPC 대화·이벤트가 끝났을 때(상점은 창을 닫을 때) ④ 스토리 진행(`> save`). 필드로 돌아온 상태(`WORLD`)일 때만 저장하고, 연출이 이어지면 끝날 때 저장된다 |
| 수동 저장 | 💾 아이콘(F) 또는 설정 → 저장 창 → 슬롯 1~5 선택 (이미 있으면 덮어쓰기 확인). 필드에서만. **로그인했을 때만** 가능 — 로그인하지 않으면 슬롯 버튼이 `🔒 저장`(비활성)이고 자동 저장만 된다. 이미 있는 수동 슬롯 불러오기는 가능 ✅ 2026-11-28 |
| 불러오기 | 저장 창의 불러오기 탭 / 타이틀 📂 불러오기 — 6개 슬롯의 이름·Lv·맵·저장 시각·출처 표시 |
| 이어하기 | 6개 슬롯 중 가장 최근 저장 |
| 보정 | 없는 맵·막힌 칸이면 시작 위치로 (콘솔에 경고) |

### 클라우드 동기화 규칙
- 슬롯마다 `savedAt` 이 더 최근인 쪽(이 기기 / 클라우드)을 쓴다.
- 로그인 직후 6개 슬롯을 비교해, 이 기기 것이 더 새로우면 올리고 클라우드 것이 더 새로우면 이 기기에 내려받는다. 슬롯 도입 전 단일 클라우드 세이브(`saves/{uid}`)는 자동 저장 슬롯이 비었을 때 자동 저장으로 옮긴다.
- 불러오기 창을 열 때마다 클라우드 슬롯을 다시 읽는다 (6회 읽기).
- 자동 저장의 클라우드 쓰기는 **20초에 최대 1번**으로 모아서 보낸다(마지막 것만). 탭을 숨기거나 닫을 때, 타이틀로 갈 때, 로그아웃할 때 남은 것을 바로 보낸다. 수동 저장과 스토리 진행(`> save`)은 즉시 쓴다.
- 로그인하지 않으면 자동 저장만 이 기기에 된다 (저장 창·타이틀에 안내).

### 2026-11-27 "자동 저장 후 로드하면 다른 곳에서 시작" 검토 결과
- 원인(추정): 예전에는 ① 일반 전투 승리 자동 저장은 **이 기기에만**, ② 스토리 자동 저장·수동 저장은 클라우드에도 기록했다. 다른 기기·다른 주소(배포 사이트 ↔ localhost 는 localStorage 가 따로다)에서 이어하면 클라우드에 남은 **예전 스토리 시점 위치**가 불러와졌다.
- 조치: 모든 저장을 같은 슬롯 구조로 이 기기·클라우드 양쪽에 기록하고, 슬롯 단위로 최신본을 고른다. 저장 창에 저장 시각·맵·출처를 보여 줘서 무엇을 불러오는지 확인할 수 있게 했다.
- 헤드리스 테스트로 인트로 후·맵 이동 후·전투 후 자동 저장 위치가 현재 위치와 같은지, 슬롯 불러오기 후 위치가 저장 위치와 같은지 확인했다.

### 플레이어 ID ✅ (2026-11-28)
- 로그인하면 계정마다 **플레이어 ID** 가 부여된다. 형식: **영문 대문자 6자리 - 숫자 10자리** (예: `QWERTY-0123456789`).
- 규칙: `SHA-256("wedge-player:" + uid)` 의 앞 6바이트 → 각 바이트 % 26 → A~Z, 다음 10바이트 → 각 바이트 % 10 → 숫자. 같은 계정이면 어느 기기에서든 같은 ID.
- 처음 로그인할 때 Firestore `players/{uid}` 에 `{ playerId, name, createdAt, lastLoginAt }` 로 저장하고, 이후에는 저장된 값을 쓴다 (`lastLoginAt` 만 갱신).
- 타이틀(로그인 상태 아래)과 설정 → 계정에 표시, `📋 복사` 버튼으로 클립보드에 복사.
- Spark(무료) 요금제만 사용. 무료 쓰기 한도(하루 2만 회)를 넘지 않도록 자동 저장의 클라우드 쓰기는 20초 간격으로 모은다.
