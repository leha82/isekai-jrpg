# 07. 게임 시스템 (UI · 퀘스트 · 성장 · 경제 · 세이브)

## 새 게임 ✅
타이틀 → **새 게임** → 주인공 이름 입력(최대 8자, 기본 '유진') → 바람결 초원에서 인트로. 이름은 대사의 `{hero}` 와 HUD·메뉴에 쓰인다.

## 화면 구성 (HUD) ✅
| 위치 | 내용 |
|---|---|
| 좌상단 | 주인공 **초상화(일러스트)**, 이름, 레벨, 골드, EXP 바 / 파티원 HP·MP 바 / **퀘스트 수 · 메인 퀘스트 제목과 설명** · ▼ 누르면 진행 중인 퀘스트 목록(드롭다운) |
| 우상단 아이콘 | 파티 · 가방 · 스킬 · 퀘스트 · 저장 · 소리 · 설정 |
| 하단 | 대화창 (화자 초상화 + 타자 효과) |
| 맵 진입 시 | 화면 가운데에 맵 이름 표시 |

## 메뉴 (M / 아이콘) ✅
| 탭 | 내용 |
|---|---|
| 파티 | 초상화, HP·MP, 공격·마력·방어, 설명, 장비 레벨·골드 |
| 가방 | 아이템 목록, 회복 아이템은 대상 동료를 골라 사용, 중요 아이템 표시 |
| 스킬 | 캐릭터별 스킬과 MP, 회복 스킬은 필드에서도 사용 |
| 퀘스트 | 진행 중 / 완료 (메인·서브 태그, 설명) |
| 설정 | **화면에 보이는 맵 크기(칸 수)**, 배경음·효과음 볼륨, 소리 끄기, 저장·불러오기, Google 로그인, 타이틀로 |
설정(화면 크기·볼륨)은 브라우저에 저장된다.

## 퀘스트 ✅
- 정의: 시나리오의 `@quest id main|side 제목` (+설명). 상태: 없음 → 진행 중(`> quest start`) → 완료(`> quest done`).
- 조건식에서 `quest id active|done|none` 으로 분기한다. 시작·완료 시 알림이 뜬다.
- 메인 4개, 서브 2개 ([03_story.md](03_story.md)).

## 성장 ✅
- 경험치·레벨은 파티 공용. 시작 Lv.1, 다음 레벨까지 20.
- 필요 경험치: `nextExp = ⌊nextExp × 1.45⌋` (`data/battle.json` 의 `levelCurve`)

| Lv | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|---|---|
| 필요 EXP | 20 | 29 | 42 | 60 | 87 | 126 | 182 | 263 | 381 |

- 레벨업 성장치는 캐릭터마다 다르다 ([04_characters.md](04_characters.md)).

## 경제 · 상점 ✅ (`data/items.json`)
- 시작 골드 60G, 시작 아이템 포션 2·에테르 1 (`data/game.json`).

| 아이템 id | 이름 | 효과 | 가격 |
|---|---|---|---|
| `potion` | 체력 포션 | HP +45 | 20G |
| `hi_potion` | 고급 포션 | HP +120 | 60G |
| `ether` | 마력 에테르 | MP +20 | 25G |
| `herb` | 은빛 약초 | 중요 아이템 (촌장의 약초) | — |
| `pendant` | 은 펜던트 | 중요 아이템 (잃어버린 펜던트) | — |

| 상점 id | 이름 | 판매 | 여관 | 장비 강화 |
|---|---|---|---|---|
| `hazel_shop` | 하젤 잡화점·여관 | 포션·에테르 | 10G | — |
| `lucen_market` | 루센 시장 | 포션·고급 포션·에테르 | 20G | — |
| `lucen_smith` | 루센 대장간 | — | — | 무기 연마(무기Lv×45G, 공격·마력+4) · 방어구 강화(방어구Lv×40G, 방어+3·HP+10) |

- 무료 회복: 엘브레아의 세계수 샘, 루센 수녀.
- 보물상자 4개(숲길·산길·요새 2) — 한 번 열면 열린 상자 그림으로 바뀐다 (`var` 변수).

## 세이브 / 불러오기 ✅
| 항목 | 내용 |
|---|---|
| 저장소 | 브라우저 `localStorage` 키 `arcadia_isekai_jrpg_save_v1` (호환을 위해 키 유지) + (로그인 시) Firestore `saves/{uid}` |
| 형식 | **version 2** — 이름·맵·좌표·방향·레벨·골드·장비·플래그·**퀘스트·변수**·인벤토리·파티 능력치 |
| 구버전 | version 1(아르카디아 시절) 세이브는 자동 변환 (리아·가렌 id 변경, 진행도에 맞춰 퀘스트·위치 설정) |
| 수동 저장 | 우측 상단 💾 또는 설정 메뉴 (필드에서만) — 로그인 시 클라우드에도 |
| 자동 저장 | 리아·가렌 합류, 흑기사 대장 격파 (클라우드 포함), 일반 전투 승리 (이 기기만) |
| 이어하기 | 타이틀에 `📂 이어하기 (이름 · Lv · 이 기기/클라우드)` — 더 최근 저장본 사용 |
| 보정 | 없는 맵·막힌 칸이면 시작 위치로 |

## 클라우드 세이브 & 로그인 ✅
Firebase Google 로그인(선택) + Firestore. 요금 조건과 설정은 [10_firebase_setup.md](10_firebase_setup.md).
- Spark(무료) 요금제만 사용. 클라우드 쓰기는 수동 저장과 스토리 진행 시점에만 한다(무료 쓰기 한도 절약).
