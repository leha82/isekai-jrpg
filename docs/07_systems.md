# 07. 게임 시스템 (성장 · 경제 · 상점 · 인벤토리 · 세이브)

## 성장 ✅

- 경험치와 레벨은 **파티 공용**이다 (`player.lv`, `player.exp`).
- 시작: Lv.1, 다음 레벨까지 필요 EXP 20
- 레벨업 후 필요 EXP: `nextExp = floor(nextExp × 1.45)` (남은 EXP는 이월)

| Lv | 필요 EXP | 누적 EXP |
|---|---|---|
| 1→2 | 20 | 20 |
| 2→3 | 29 | 49 |
| 3→4 | 42 | 91 |
| 4→5 | 60 | 151 |
| 5→6 | 87 | 238 |

- 레벨업 보너스(전원): HP +14, MP +5, ATK +3, MATK +4, DEF +2, HP/MP 완전 회복

## 경제 ✅

- 시작 골드: **60 G**
- 수입: 전투 승리 보상만 있음 ([06_monsters.md](06_monsters.md))
- 지출: 상점, 여관, 장비 강화

## 상점 & 여관 ✅

이용 장소: **시작의 마을 (2,5)**, **아르카디아 왕국 (11,5)** (가렌 합류 후)

| 항목 | 가격 | 효과 |
|---|---|---|
| 🛏️ 여관 휴식 | 15 G | 파티 전원 HP/MP 완전 회복 |
| 🧪 체력 포션 | 20 G | 아이템 +1 |
| 💧 마력 에테르 | 25 G | 아이템 +1 |
| ⚔️ 파티 무기 연마 | `무기Lv × 45` G | 전원 ATK +4, MATK +4 (영구) |
| 🛡️ 파티 방어구 강화 | `방어구Lv × 40` G | 전원 DEF +3, 최대 HP +10 (영구) |

- **왕가의 명검:** 가렌이 합류할 때 무기 Lv이 무료로 +1 된다 (전원 ATK/MATK +4).
- **엘프의 숲 성소:** 리아가 합류한 뒤에는 무료 완전 회복 지점이 된다.

## 인벤토리 ✅

시작 시 포션 2개, 에테르 1개. 필드에서는 `I` 키 또는 🎒 버튼으로 연다.

| 아이템 | 필드 사용 | 전투 사용 |
|---|---|---|
| 🧪 체력 포션 | HP가 가장 낮은 부상자 1명 HP +45 | HP가 가장 낮은 생존자 1명 HP +45 |
| 💧 마력 에테르 | 파티 전원 MP +15 | MP 비율이 가장 낮은 생존자 1명 MP +20 (유진 커맨드) |

> 에테르는 필드와 전투에서 효과가 다르다. 필드에서는 전원, 전투에서는 1명에게 더 많이 회복된다.

| 키 | `arcadia_isekai_jrpg_save_v1` |

## 클라우드 세이브 & 로그인 ✅

**채택: B안 (Firebase Google 로그인 + Firestore), 2026-11-27 구현.** 로그인은 **선택 사항**이며, 로그인하지 않아도 지금처럼 이 기기에 저장된다.
콘솔 설정 방법은 [10_firebase_setup.md](10_firebase_setup.md)를 보세요.

### 동작 사양

| 항목 | 내용 |
|---|---|
| 로그인 | 타이틀 `🔑 Google 로그인` 또는 게임 중 우측 상단 `🔑 로그인` (Google 팝업) |
| 로그아웃 | 같은 버튼(`🔓 로그아웃`), 확인 창 표시. 로그아웃 후에는 이 기기에만 저장됨 |
| 클라우드 위치 | Firestore `saves/{uid}` 문서 1개 (세이브 슬롯 1개) |
| 클라우드에 저장하는 시점 | `💾 저장` 버튼, 리아 합류, 가렌 합류 (로그인 상태일 때만) |
| 이 기기에만 저장하는 시점 | 일반 전투 승리 자동 저장 (Firestore 무료 쓰기 한도 절약) |
| 저장 순서 | 항상 이 기기에 먼저 저장 → 로그인 상태면 클라우드에도 저장. 클라우드 실패 시 오류 토스트만 표시 (이 기기 세이브는 유지) |
| 불러오기·이어하기 | 클라우드 세이브를 새로 받아온 뒤, 이 기기와 클라우드 중 **`savedAt`이 더 최근인 쪽**을 사용. 클라우드 세이브를 쓰면 이 기기에도 복사 |
| 로그인 직후 | 클라우드가 비어 있고 이 기기에 세이브가 있으면 이 기기 세이브를 클라우드로 업로드. 게임 중 로그인했는데 클라우드 세이브가 있으면 "📂 불러오기로 가져올 수 있습니다" 안내 (자동으로 덮어쓰지 않음) |
| SDK 로드 실패 | 오프라인이거나 CDN이 막히면 버튼이 `☁️ 사용 불가`로 바뀌고, 이 기기 저장만으로 정상 플레이 |

### 검토했던 다른 안 (기록용)

현재 세이브는 브라우저 `localStorage`에만 있으므로 **로그인 없이 동작**한다. 로그인은 다른 기기에서 이어하기나 브라우저 데이터 삭제 대비가 필요할 때만 의미가 있다.
GitHub Pages는 정적 호스팅이라 서버 없이 쓸 수 있는 방식 위주로 검토했다.

| 안 | 방식 | 기기 간 이어하기 | 장점 | 단점 |
|---|---|---|---|---|
| A | 세이브 코드/파일 내보내기·가져오기 | 직접 옮김 | 로그인·서버·외부 의존성 없음 | 자동 동기화 아님 |
| B | Firebase Auth(Google 로그인) + Firestore | 자동 | 무료 등급으로 충분, 정적 사이트에서 동작 | Firebase SDK CDN 의존, 콘솔 설정·보안 규칙 필요 |
| C | Supabase Auth + Postgres | 자동 | 로그인 방식 다양 | 무료 등급은 미사용 시 일시정지 |
| D | 자체 서버 + 계정 DB | 자동 | 완전한 통제 | 서버 운영, 비밀번호 보안 부담 — 비추천 |

- 사용자가 B를 선택했다. A(세이브 코드 내보내기)는 오프라인 백업용으로 나중에 추가할 수 있다. 💡
- **보안 규칙:** `saves/{uid}` 문서는 `request.auth.uid == uid`일 때만 읽고 쓸 수 있다. 저장소 루트 [`firestore.rules`](../firestore.rules)에 보관한다.

### Firebase 요금 조건 (2026-11-27 공식 문서 기준)

- **Spark(무료) 요금제만 사용한다.** 카드 등록이 필요 없고, 무료 한도를 넘으면 그 달 남은 기간 동안 해당 기능만 멈춘다. 요금은 청구되지 않는다.
- Blaze(종량제)는 Firestore·Auth에 고정 요금 상한을 걸 수 없으므로 업그레이드하지 않는다.
- Spark 무료 한도: Auth 하루 활성 사용자 3,000명 / Firestore 쓰기 20,000회·읽기 50,000회(매일 초기화) / 저장 용량 1 GiB.
- **클라우드 쓰기 절약 원칙:** 클라우드 저장은 수동 저장과 스토리 진행 시점에만 한다. 전투 승리 자동 저장은 로컬(`localStorage`)에만 한다.
- 2026-12-01 과금 변경은 Remote Config에만 해당하며, 이 게임은 Remote Config를 쓰지 않는다.
- 출처: [요금제](https://firebase.google.com/docs/projects/billing/firebase-pricing-plans), [Firestore 한도](https://firebase.google.com/docs/firestore/quotas), [Auth 한도](https://firebase.google.com/docs/auth/limits)
