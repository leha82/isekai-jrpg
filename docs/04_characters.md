## 5가지 스탯 ✅ (2026-11-28)

모든 캐릭터와 **몬스터**가 STR·DEX·AGI·CON·INT 를 가진다. 계수는 `data/battle.json` 의 `stats` (관리자 '전투 설정' 탭).
파티·장비 메뉴에는 5스탯과 함께 계산값(공격력·마력·방어력·치명타·회피)도 보인다. 칸을 누르면 설명 팝업이 뜬다 (2026-11-28 4차 — 장비의 공격·방어 보너스가 눈에 보이도록).

| 스탯 | 이름 | 영향 | 계수 (현재) |
|---|---|---|---|
| STR | 힘 | 공격력 (물리 스킬 피해) | 1당 공격 +2 |
| DEX | 솜씨 | 치명타율 · 회피율 조금 | 1당 치명 +0.5%, 회피 +0.2% |
| AGI | 민첩 | 회피율 · 치명타율 조금 | 1당 회피 +0.6%, 치명 +0.1% |
| CON | 체력 | 최대 HP · 방어력 | 1당 HP +5, 방어 +0.5 (버림) |
| INT | 지능 | 최대 MP · 마력 (마법 피해·회복량) | 1당 MP +2, 마력 +2 |

```
공격 = 기본 공격 + STR×2          마력 = 기본 마력 + INT×2          방어 = 기본 방어 + ⌊CON×0.5⌋
HP  = 기본 HP + CON×5             MP  = 기본 MP + INT×2
치명타율 = 4% + DEX×0.5% + AGI×0.1%  (상한 50%)    회피율 = AGI×0.6% + DEX×0.2%  (상한 35%)
+ 장비 보너스(스탯·공격·방어 등) + 대장간 강화(무기 Lv·방어구 Lv)
```
- 레벨이 오르면 `growth` 만큼 스탯과 기본 HP·MP·방어가 오른다 (소수는 레벨마다 더한 뒤 버림). 레벨은 파티 공용이고, 레벨업하면 HP/MP 가 가득 찬다.
- 능력치는 저장하지 않고 **레벨·스탯·장비·강화로 매번 계산**한다 (`calcMemberStats`, `js/core/state.js`).
- 합류하지 않은 동료도 레벨을 함께 올린다.

## 장비 ✅ (2026-11-28)
캐릭터마다 **무기 · 방어구 · 장신구** 3칸. 메뉴의 장비 탭(E)에서 캐릭터를 골라 가방의 장비를 끼우고 뺀다. 장비 목록·가격은 [07_systems.md](07_systems.md#장비-).
- 아이템의 `for` 에 있는 캐릭터만 장착할 수 있다 (비어 있으면 누구나).
- 대장간의 '파티 무기 연마 / 방어구 강화'는 장비와 별개로 파티 전원에게 더해진다.

## 새 캐릭터 추가
1. 외형: `tools/gen_assets.py` 의 `CHARACTERS` 목록 **끝에** 추가하고 다시 실행 (머리 모양·색·망토·투구·수염 등 매개변수). 전투 배경 PNG 는 실행할 때마다 조금씩 달라지므로 바뀌었으면 되돌린다.
2. 파티원: 관리자 '캐릭터·몬스터' 탭 또는 `data/characters.json` 의 `party` 에 추가 (`base`·`stats`·`growth`·`equip`·`skills`)
3. 합류 이벤트: 시나리오에서 `> join id`
4. 초상화: `tools/gen_svg.py` 의 `PORTRAITS` 에 추가 후 실행, `characters.json` 의 `portraits`·`speakerPortraits` 에 등록
