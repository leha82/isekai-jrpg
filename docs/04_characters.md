# 04. 캐릭터

## 파티 캐릭터

### 유진 — 이세계인 (주인공) ✅
- **코드 id:** `hero` / 스프라이트 `hero` / 처음부터 합류
- **배경:** 현대의 평범한 직장인. 퇴근길에 소환 술식의 오차로 시작의 초원에 떨어졌다.
- **특성:** 이 세계 마력 회로가 백지 상태라 속성 마법과 경험치를 빠르게 흡수한다.
- **성격:** 상식적이고 논리적이다. 누군가를 희생시키는 해법을 받아들이지 않는다.
- **전투 역할:** 밸런스형 마검사 (물리 + 화염 마법 + 단일 회복), 파티 아이템 관리

### 리아 — 엘프 궁수 (동료 1) ✅
- **코드 id:** `elf` / 스프라이트 `elf` / 엘프의 숲 성소에서 합류 (flag 0 → 1)
- **배경:** 세계수를 지키는 엘프 정찰병. 유진의 순수한 영혼 파장을 가장 먼저 알아본다.
- **성격:** 침착하고 예의 바르다. 안내자 역할.
- **전투 역할:** 원거리 딜러 + 파티 전체 치유 서포터

### 가렌 — 왕국 기사 (동료 2) ✅
- **코드 id:** `knight` / 스프라이트 `knightAlly` / 아르카디아 왕국에서 합류 (flag 1 → 2)
- **배경:** 아르카디아 왕국 기사단장. 전장 경험이 많은 베테랑 전사.
- **성격:** 호탕하고 의리가 있다. 국왕에게 받은 '왕가의 명검'을 유진에게 건넨다.
- **전투 역할:** 탱커 + 고화력 물리 딜러 (피해 반감 방어)

3. 합류 이벤트는 시나리오 스크립트에서 `> join id` 로 작성 ([11_scenario.md](11_scenario.md))

5. 세이브 포맷은 `party`의 `id`로 매칭하므로 따로 수정할 필요 없음
6. 이 문서와 [05_battle.md](05_battle.md)에 능력치와 스킬 기록
