# 02. 세계관 & 맵

## 베일하르트 대륙

하늘에 '장막(veil)'처럼 겹친 빛이 갈라지는 대륙. 마법을 다루는 **루센 왕국**, 세계수를 지키는 **엘브레아의 엘프**, 산맥의 **그롬 드워프**, 북동쪽 설원 너머의 **녹턴 요새**가 있다.

### 세계의 비밀 (스토리 핵심)
- 천 년 동안 마법을 남용한 탓에 하늘에 **균열**이 생겨 대륙이 무너지고 있다.
- 사람들이 마왕이라 부르는 **세계 관리자 오르벨**은 균열을 막으려던 고대 대마법사다.
- 균열을 봉인하려면 이 세계 마력에 물들지 않은 **외부 영혼('쐐기')** 이 필요하다고 계산해 소환 술식을 썼고, 오차로 주인공이 초원에 떨어졌다.
- 녹턴의 흑기사들이 주인공을 쫓는 이유는 '쐐기'를 회수하기 위해서다.

## 맵 (12개) ✅

맵 데이터는 `data/maps/<id>.json`, 생성기는 `tools/gen_maps.py`, 편집은 관리자 페이지 '맵 디자인' 탭에서 한다.

| id | 이름 | 크기 | 배경음 | 몬스터 | 연결 |
|---|---|---|---|---|---|
| `meadow` | 바람결 초원 | 40×30 | field | 슬라임·박쥐 | 북→하젤, 동→숲길 |
| `hazel` | 하젤 마을 | 28×22 | town | — | 남→초원, 촌장의 집 문 |
| `hazel_elder` | 촌장의 집 (실내) | 11×10 | town | — | 문→하젤 |
| `forest_road` | 속삭이는 숲길 | 36×24 | field | 고블린·독 슬라임·박쥐 | 서→초원, 동→엘브레아, 북→루센 (리아 합류 후) |
| `elbrea` | 세계수의 숲 엘브레아 | 30×30 | forest | — | 서→숲길 |
| `lucen` | 왕도 루센 | 34×28 | castle | — | 남→숲길, 성문→알현실, 동쪽 북문→그롬 (가렌 합류 후) |

- 맵이 화면보다 크면 카메라가 주인공을 따라 스크롤하고, 작으면 가운데에 놓인다.
- 한 화면에 보이는 칸 수는 설정 메뉴에서 10·13·16·20·26칸 중에 고른다. (`data/game.json` 의 `views`)
- 시작 위치: 초원 (8,22). 전멸 시 부활: 하젤 마을 (13,19). (`data/game.json`)

### 출구(워프)와 조건
출구는 맵 데이터의 `warps` 에 있다. `cond`(시나리오 조건식)가 맞지 않으면 이동하지 않고 `fail` 장면을 실행한다.

| 출구 | 조건 | 막혔을 때 장면 |
|---|---|---|
| 숲길 북쪽 → 루센 | `flag >= 1` (리아 합류) | `lucen_road_closed` |
| 루센 북문 → 그롬 산길 | `flag >= 2` (가렌 합류) | `north_gate_closed` |
| 녹턴 성문 → 요새 내부 | `flag >= 3` (흑기사 대장 격파) | `noct_gate_sealed` |

## 지도 (메뉴 '지도' 탭 · 단축키 M) ✅ (2026-11-28)
- **월드 지도:** `data/game.json` 의 `worldMap` 에 적은 위치(0~100 좌표, 북쪽이 위)에 지역을 점으로 그리고, 맵 출구(`warps`)로 이어진 지역끼리 길을 잇는다.
  가 본 지역(`player.visited`, 세이브됨)만 이름이 보이고, 가 본 곳과 이어진 지역은 `???` 로 보인다. 지금 있는 지역에 빨간 표시.
  실내 맵은 `{ "parent": "바깥 맵 id" }` 로 바깥 지역에 포함된다 (촌장의 집 → 하젤, 알현실 → 루센, 옥좌 → 요새 내부).
- **현재 지역:** 지금 맵 전체를 타일 평균색으로 축소해 그리고, 지나갈 수 없는 칸은 어둡게, 출구(자홍색)·사람(파랑)·나(빨강)를 표시한다. 아래에 출구 방향과 도착 지역 이름.
- 새 맵을 만들면 `worldMap` 에 위치를 추가한다 (없으면 월드 지도에 나오지 않는다).

## 맵 진입 이벤트 ✅ (2026-11-28)
시나리오 `@event` 에 `* trigger enter` 를 주면 그 맵으로 **출구를 통해 들어올 때** 실행된다 (좌표는 쓰이지 않는다). `* when 조건` 으로 한 번만 실행되게 한다.
예: 하젤 마을 `hazel_tobi_arrive` — 토비가 파티에 있고 `main_village` 가 끝나지 않았을 때 토비의 귀가 장면. ([11_scenario.md](11_scenario.md))

## 타일 (73종)

`data/tiles.json` — 인덱스가 맵 데이터 값이다. 지형(ground)과 오브젝트(objects) 두 층으로 칠한다.

| 분류 | 타일 |
|---|---|
| 지형 (인카운트 O) | 풀밭·꽃밭·숲 바닥·눈밭·얼음·동굴 바닥·요새 바닥 |
| 지형 (인카운트 X) | 흙길·모래·다리·돌바닥·자갈길·나무 바닥·양탄자·대리석 |
| 지형 (통행 불가) | 물(물결 애니메이션)·어둠·절벽·눈 절벽·요새 벽 |
| 자연 | 나무·열매나무·전나무·눈 덮인 전나무·고목·덤불·긴 풀·꽃·바위·세계수(2×2)·샘·수정·동굴 입구 |
| 마을·성 | 울타리·표지판·보물상자(열림)·통·상자·우물·항아리·지붕·벽·창문·문·성벽·성문·깃발·기둥·옥좌·횃불·석상·차원문 |
| 실내 | 계산대(너머의 사람과 대화 가능)·책장·침대·탁자·계단 |

## 맵 수정 방법
1. 관리자 페이지 → '맵 디자인' 탭에서 타일을 칠하고 속성·인카운트·출구를 바꾼 뒤 💾 맵 저장. ([13_admin.md](13_admin.md))
2. 거점의 NPC·대화는 시나리오의 `@event id 맵id:x,y 이름` 블록으로 추가한다. ('이벤트' 탭에서 맵을 클릭해 만들 수도 있다)
3. 이 문서의 맵 표를 갱신한다.
