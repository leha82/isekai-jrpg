# isekai-jrpg — 아르카디아 연대기

브라우저에서 동작하는 단일 파일 이세계 전생 JRPG입니다. (HTML5 Canvas + Web Audio, 외부 의존성 없음)

## ▶ 바로 플레이
**https://leha82.github.io/isekai-jrpg/**

## 실행 방법
- **간단히:** `index.html`을 브라우저로 엽니다.
- **로컬 서버:** `python -m http.server 8000` 실행 후 http://localhost:8000 접속
- **VS Code:** `Ctrl+Shift+B`로 서버 실행, `F5`로 브라우저 디버그 실행

## 조작
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Space / Enter | 조사·대화 진행 |
| I | 가방 |
| Esc | 창 닫기 |

화면 아래 가상 패드로 마우스·터치 조작도 가능합니다.
진행 상황은 우측 상단 `💾 저장` / `📂 불러오기` 버튼으로 브라우저에 저장할 수 있습니다. 동료가 합류하거나 전투에서 이기면 자동으로 저장되고, 타이틀 화면에서 이어하기를 할 수 있습니다.
`🔑 Google 로그인`을 하면 세이브가 클라우드에도 저장되어 다른 기기에서도 이어할 수 있습니다. 로그인은 선택 사항입니다.
