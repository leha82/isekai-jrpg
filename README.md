# 쐐기의 이방인 — 베일하르트의 균열

퇴근길 지하철에서 이세계 '베일하르트'로 떨어진 이방인의 이야기. 브라우저에서 바로 즐기는 도트 턴제 JRPG입니다. (빌드 도구 없음)

## ▶ 바로 플레이
**https://leha82.github.io/isekai-jrpg/**

## 특징
- 맵 12개를 걸어 다니는 스크롤 맵, 4방향 걷기 애니메이션, 화면 크기(보이는 칸 수) 설정
- 주인공 이름 입력, 메인 퀘스트 4장 + 서브 퀘스트
- 캐릭터가 달려 나가 싸우는 사이드뷰 전투 (마법·회복·방어 이펙트, 적 1~3마리, 보스 2)
- 직접 작곡한 배경음 11곡과 효과음 (MP3)
- 이 기기 저장 + Google 로그인 클라우드 세이브

## 조작
| 키 | 동작 |
|---|---|
| 방향키 (누르고 있기) | 이동 |
| Space / Enter | 말 걸기·조사 / 대화 넘기기 |
| P · I · E · S · Q · M | 파티 · 가방 · 장비 · 스킬 · 퀘스트 · 지도 |
| F · N · O(Esc) | 저장 · 소리 · 설정 |
| 전투 중 방향키 + Enter (또는 숫자 1~9) | 커맨드 선택 |

화면 아래 가상 패드(누르고 있으면 이동)와 우측 상단 아이콘으로 마우스·터치 조작도 가능합니다.

## 실행 (개발)
- **VS Code:** `F5` → 로컬 서버가 켜지고 브라우저에서 열립니다.
- **로컬 서버:** `python -m http.server 8000` → http://localhost:8000
- `index.html` 을 파일로 직접 열면 데이터·시나리오를 불러올 수 없어 실행되지 않습니다.

## 구조
- `js/` 게임 코드 · `data/` 게임 데이터(JSON) · `assets/` 그래픽·음원 · `scenario/` 대화·이벤트 스크립트 (암호화)
- `tools/` 그래픽·초상화·음원·맵 생성기 (외부 리소스 없이 직접 생성)
- `admin.html` 관리자 모드 (지정된 관리자 전용)
- `docs/` 기획 문서
