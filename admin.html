🔐 GitHub 토큰 설정

암호화된 스크립트와 게임 데이터를 GitHub 저장소(leha82/isekai-jrpg)에 커밋하려면 토큰이 필요합니다. 토큰은 Firebase의 관리자 전용 문서에 보관되며, 관리자가 아니면 읽을 수 없습니다.

  1. GitHub → Settings → Developer settings → Fine-grained personal access tokens → Generate new token
  2. Repository access: Only select repositories → 이 저장소만 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. 생성된 토큰(github_pat_...)을 아래에 붙여 넣기
